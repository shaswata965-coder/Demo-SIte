Design summary · Demo-Totem

AXON — one model, seven rooms

A scroll-driven site in the spirit of totem.itsoffbrand.com: one object that transforms as you scroll. Here the object is a neural model, and the brand is AXON, a fictional consultancy that makes LLMs cheaper to serve. Every name and figure is invented.

Intuition

The model is the brand

AXON sells efficient inference, so the hero asset is a live network. Scroll turns it, rewires it and moves it. It never spins on its own.

The copy becomes the network

On the flooded sections the model comes apart. Its units bead the wiring between content nodes, then fly back to rebuild it.

A room per section, not a tint

Every section changes the whole colour set at once. Seams blend in OKLab so bands grow into each other instead of cutting.

Read like an instrument

Headlines type in, a scan beam reveals body copy line by line, and a circuit layer wires the text to the model.

Colour

Five skins. A skin is the ground, panel, ink, four hues and how the model is drawn (as ink or as light). Each also has a dark variant. There is no green.

Magenta = live. Pulses, what's running.
  • Colours are assigned by role, never by position. A flooded skin swaps only the roles its own ground would swallow. On violet, for example, yellow takes over action.
  • Every value is solved rather than picked by eye. Each hue is pushed to full chroma, then to the lightness closest to the pure hue that still clears 4.5:1 on its ground and panel.
  • The accent comes in two versions. --accent #FF5F0C is the fill and --accent-ink #CA4500 is the same hue as readable text.
  • The model's hues are the page's hues, so the canvas and the copy read as one palette.

  • Visual variety. Sections alternate between the model standing whole and the model taken apart. Each taken-apart section uses a different network shape: feed-forward, hub and spokes, clusters.
  • No monotony. No two consecutive sections share a flood colour. The page never has more than two dimmed-model screens in a row, because four read as "switched off".
  • People. The four team portraits differ in skin tone, build, tilt and halo, so they read as four distinct people. Names come from a range of backgrounds: Mara Ostrowski, Ifeanyi Balogun, June Park, Tomáš Vrba.
  • Type range. Archivo's width axis (75–125) carries display type, IBM Plex Sans the body and Plex Mono the data.

Tech assets

Neural renderer

Custom 3D point-graph on 2D canvas, with no WebGL so it opens on any phone. It has seven arrangements (helix, shells, layers, globe, vault, ledger, core), three quality tiers and a frame-time governor.

Generated imagery

Project thumbnails and portraits are inline SVG drawn from the page's colour tokens. External image hosts are blocked by the embed CSP, and inline SVG themes itself for free. Each image is labelled as generated.

Partner marks

Neutral geometric glyphs in one SVG sprite, deliberately not anyone's logo. The real company names are placeholders and carry a visible disclaimer. The only testimonial is fictional and says so.

Circuit & instrument layer

A PCB bus in the margins, a chip fanning into a small 4-3-1 network, and a scan beam with scanlines. Everything that moves runs only on the screen you're looking at.

Production stack: Next.js 15 · React Three Fiber · GSAP ScrollTrigger · Lenis · Tailwind v4 (reading the same tokens) · Sanity, so motion parameters are editable content · Vercel.
